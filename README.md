### About Me

Software engineer and **MS Computer Science graduate from USC (May 2026)**. I build AI agents and the backend systems around them: a computer-use automation system that learns a legacy web task once with an LLM and then replays it with no model, a voice bot that phones an AI receptionist over real phone lines, a GPT-4 pipeline at Fiscali that turned financial agreements into structured data 3x faster, and churn models serving 1.2M+ users on AWS.

Currently looking for **new-grad software engineering roles** in backend, AI/LLM systems, and full-stack development. See everything at **[ishan0410.github.io](https://ishan0410.github.io)**.
